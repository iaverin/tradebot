# Подводящая задача к дешбордам
Нужно привести статусы ордеров к единой форме. И соответсвующим образом обновить табличку в базе (не стирать уже записанные).

- датавремя создания ордера
- датавремя исполнения ордера
- cтатус ордера: ошибка, отменен, в процессе, выполнен
- кол-во поставленных контрактов
- цена по которой выставлял ордер
- cумма выставленного ордера в деньгах
- кол-во исполненных контрактов
- суммма исполнения

(для примера см как ордер буки приводятся к общему виду)


# Дешборды

1. Свобный отчет по оппортьюнити с ордерами
Суть отчета - показать кол-во оппотрьюнити, сгруппированных по парам и присоединенных с количеством/статусами ордеров.

Фильтры:
- дата с
- дата по
- показать только с выставленными ордерами
фильтр по датам применяется к датам создания оппортьюнитей

Аггрегаты/Итого (можно в виде плашек):
- кол-во оппортьюнитей всего
- кол-во уникальных пар в оппортьюнитях
- кол-во выставленных ордеров КАЛШИ/ПОЛИМАРКЕТ

Строки отчета:
- дата создания оппортьюнити
- Пара рынков: формат ( <a href='ссылка на евент'>EventTitlePolyMarket</a>. MarketTitlePolymarket / <a href='ссылка на евент'>EEventTitleKalshi</a>. MarketTitleKalshi)
- дата закрытия рынка полимаркет/калши
- Кол-во зареганных оппортьюнитей по паре
- Кол-во удачно выставленных пар ордеров: всего пар ордеров (пара ордеров = 1 ордер на калши + 1 ордер на полимаркет)
- Кол-во исполненных ордеров: полимаркет/калши

2. Отчет по потенциальному профиту
Фильтры:
- дата с
- дата по
- дата закрытия: Полимаркет или Калши (по умолчанию полимаркет)

фильтр по датам применяется к датам закрытия маркета/ивента и соответветственно под эти даты подтягиваются оппортьюнити

Аггрегаты/Итого (можно в виде плашек):
- Сумма сколько поставили в ордерах за период
- Сумма ожидаемого профита за период

Строки отчета:
- Дата
- Кол-во уникальных пар, которые будут закрыты в эту дату (в соответствии с фильтрами)
- Кол-во оппортьюнитей
- Сумма размеров созданных ордеров по соответствующим оппортьюнити
- Сумма размеров испроненных ордеров по соответствующим оппортьюнити
- Сумма профитов по созданным ордерам.
  Считается как: Кол-во созданных пар ордеров * (1 - (сумма ордера Полимаркет + сумма ордера Калши)) (вроде так)

- Сумма профитов по исполненным ордерам.
  Считается как: Кол-во созданных пар ордеров * (1 - (сумма ордера Полимаркет + сумма ордера Калши)) (вроде так)
